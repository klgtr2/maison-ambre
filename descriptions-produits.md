# Descriptions produits — à coller dans Shopify

Pour chaque produit importé avec BigBuy ou Eprolo :
1. Ouvrez la fiche dans Shopify (Produits > le produit).
2. Collez le **titre**, puis le texte de la **description** dans le champ « Description ».
3. En bas de la fiche, dans « Référencement sur les moteurs de recherche », collez le **titre SEO** et la **méta-description**.
4. Vérifiez que les informations (contenance, matière, quantité) correspondent bien au produit du fournisseur, et complétez-les si besoin.

Les mêmes textes sont utilisés sur le site, dans `catalogue-produits.js`.
